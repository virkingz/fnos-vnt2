手动上传核心

      

        网络不通、镜像没有该版本，或想指定某个版本时，可自行下载核心后在这里上传。

        支持两种文件：vnt2-*-linux-musl-v*.zip（推荐，从
        Releases 下载）
        或直接上传解压出的 vnt2_web 文件。

面板端口

      
对外访问端口。管理页与组网面板都通过它访问；修改后服务会自动重启，请用新端口重新打开。

      

        
        
      

      

    


    

      
组网面板监听范围

      

        控制 vnt2_web（组网面板）监听在哪个地址。

        组网面板由 vnt2_web 以自己的端口独立提供，桌面上的「VNT 组网面板」图标
        直接打开它；改这里会影响该图标与跳转是否能从其它设备访问。
      

      

        
        
      

      

      

    


    

      
下载源与代理

      

        两项相互独立，可只配其一，也可同时使用。

        镜像前缀：把下载地址改写到镜像站（如 https://ghfast.top），只需 URL 拼接。

        网络代理：让请求经由代理隧道出去，适合本机需要通过代理才能访问外网的场景。
